Preferences

Settings

Everything here applies to new meetings on this device. Nothing is synced anywhere.

Privacy

Local-only mode keeps audio, transcription and notes on this device and disables every network request.

Speech-to-text

How meeting audio becomes text. Deepgram streams audio to its servers for real-time results; local Whisper runs entirely in this browser.

Used straight from this browser. The key travels in a WebSocket header, never in a URL.

AI notes

Optional. Sends finalised transcript text — never audio — to a provider you choose, and fills in the summary sections. Your key is used directly from this browser.

The key is saved in this browser only and is sent straight to the provider. Anyone using this browser profile — or any extension with page access — could read it. Use a key with a spending limit.

While a meeting runs, notes refresh about every 25 seconds and once more at the end, so a long meeting makes repeated requests on your key.

OpenAI currently blocks direct browser requests, so its requests fail unless you set an API base URL pointing at a proxy or gateway. OpenRouter reaches GPT models without that.

Local Whisper

Settings for the offline engine. Larger chunks are more accurate but appear later; overlap re-reads the end of each chunk so words are not lost between them. Ignored while Deepgram is selected.

Advanced capture details
WebGPU runs Whisper on the GPU. Without it Chrome falls back to single-threaded WebAssembly, which needs a few seconds per update.
